1935年，中华民族正处于生死存亡的关键时刻。年仅23岁的聂耳怀着对祖国深深的热爱，为田汉创作的歌词《义勇军进行曲》谱曲。

这首歌曲原本是电影《风云儿女》的主题歌，却成为了唤醒民族精神的时代强音。歌曲以其激昂的旋律、铿锵的节奏，唤起了无数中华儿女的爱国热情。

从诞生之日起，《义勇军进行曲》就伴随着中华民族的抗争历程，见证了从抗日战争到新中国成立的光辉历史，最终成为了中华人民共和国国歌。
