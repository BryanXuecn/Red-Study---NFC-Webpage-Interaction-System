# NFC网页交互系统项目结构说明

## 项目概述

红色研学NFC网页交互系统是一个基于Web技术的文化传承平台，通过NFC芯片与印章交互，为用户提供沉浸式的红色文化体验。项目采用古典中华美学与现代Web技术相结合的设计理念。

## 技术栈说明

### 前端技术
- **HTML5**: 语义化标签、Web API
- **CSS3**: 变量系统、动画、Grid/Flex布局
- **JavaScript ES6+**: 模块化、Promise、Class语法
- **Web NFC API**: 芯片读取（Android设备）

### 设计特色
- **古典中华美学**: 传统色彩、书法元素、建筑造型
- **响应式设计**: 移动端优先、多设备适配
- **无障碍支持**: 语义化标签、键盘导航
- **性能优化**: 资源预加载、动画优化

### 浏览器支持
- **Android**: Chrome 89+, Samsung Internet 15+
- **iOS**: Safari（NFC功能不支持，提供备用方案）
- **桌面**: Chrome, Firefox, Safari, Edge

## 部署和运行

### 本地开发
1. 运行 `start-server.bat` 启动服务器
2. 手机访问: `http://[电脑IP]:8080`
3. 开发调试: 使用浏览器开发者工具

### 生产部署
- **HTTPS要求**: NFC功能必须使用HTTPS
- **服务器配置**: 支持静态文件服务
- **CDN优化**: 图片和音频文件加速
- **缓存策略**: 合理的资源缓存设置

## 注意事项

### NFC功能限制
- **iOS限制**: Safari不支持Web NFC，需提供备用方案
- **Android要求**: Chrome 89+，需要HTTPS协议
- **权限管理**: 需要用户授权NFC权限

### 性能考虑
- **图片优化**: 压缩和懒加载
- **音频处理**: 格式兼容性和预加载
- **动画性能**: 使用硬件加速
- **网络适配**: 弱网环境优化

### 安全要求
- **HTTPS**: 生产环境必须使用
- **数据验证**: NFC数据校验
- **错误处理**: 完善的异常捕获
- **隐私保护**: 不收集敏感信息
