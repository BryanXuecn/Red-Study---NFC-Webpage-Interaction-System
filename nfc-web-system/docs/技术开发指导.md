# 红色研学NFC网页交互系统技术开发指导

## 项目概述

本项目基于现代前端技术，打造沉浸式红色文化传承平台。采用现代化设计理念融合传统文化元素，通过NFC芯片自动跳转实现便捷访问，为用户提供流畅优雅的文化体验。

### ✅ 已完成模块
- **01-宣言馆-墨韵真理**: 已完成现代化改造，包含NFC访问成功状态、现代UI设计

### 🚧 待开发模块
- **02-国歌馆-觉醒之声**: 待开发，音频可视化主题
- **03-滨江馆-城市之芯**: 待开发，城市变迁对比主题

## 技术架构

### 核心技术栈
- **前端框架**: 原生HTML5 + CSS3 + JavaScript ES6+
- **NFC技术**: Web NFC API (NDEFReader)
- **样式系统**: CSS变量 + BEM命名 + 响应式设计
- **音频处理**: Web Audio API + HTML5 Audio
- **动画引擎**: CSS3 Animation + JavaScript控制

### 设计原则
- **古典美学**: 传统中华文化元素与现代技术融合
- **响应式优先**: 移动端为主，桌面端适配
- **性能优化**: 资源预加载、硬件加速、代码分割
- **无障碍支持**: 语义化标签、键盘导航、屏幕阅读器

class NFCHandler {
  constructor() {
    this.isSupported = 'NDEFReader' in window;
    this.isReading = false;
    this.callbacks = { onRead: null, onError: null, onStatusChange: null };
  }
  
  // 支持标签验证
  validateManifestoTag(data) {
    for (const record of data.data) {
      if (record.data && typeof record.data === 'string') {
        if (record.data.includes('manifesto') || 
            record.data.includes('宣言馆') ||
            record.data.includes('xuanyan')) {
          return true;
        }
      }
    }
    return false;
  }
}

#### 对比滑动实现
```javascript
class ImageComparison {
  constructor(container) {
    this.container = container;
    this.slider = container.querySelector('.comparison-slider');
    this.isDragging = false;
    this.bindEvents();
  }
  
  bindEvents() {
    this.slider.addEventListener('mousedown', this.startDrag.bind(this));
    this.slider.addEventListener('touchstart', this.startDrag.bind(this));
  }
  
  startDrag(e) {
    this.isDragging = true;
    const rect = this.container.getBoundingClientRect();
    const x = (e.clientX || e.touches[0].clientX) - rect.left;
    const percentage = (x / rect.width) * 100;
    
    this.updateComparison(percentage);
  }
}
```

### 生产环境配置

#### Nginx配置示例
```nginx
server {
    listen 443 ssl http2;
    server_name your-domain.com;
    
    # SSL配置（NFC功能必需）
    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;
    
    # 静态资源缓存
    location ~* \.(css|js|png|jpg|jpeg|gif|svg|woff2)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
    
    # 音频文件优化
    location ~* \.(mp3|ogg|wav)$ {
        expires 7d;
        add_header Cache-Control "public";
        add_header Accept-Ranges bytes;
    }
    
    # HTML文件不缓存
    location ~* \.html$ {
        expires 0;
        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }
}
```
