## 模块概述

"墨韵真理"是红色研学NFC交互系统的核心展示模块，专为《共产党宣言》展示馆设计。采用宏伟古典的中华美学风格，通过NFC芯片与墨水瓶印章的交互，为参观者提供沉浸式的红色文化传承体验。

## 📱 使用流程

### 标准NFC体验流程
1. **进入页面**: 欣赏红旗飘扬的庄严加载动画
2. **NFC感应**: 将墨水瓶印章靠近手机NFC区域
3. **标签验证**: 系统自动验证印章标签
4. **触发体验**: 成功识别后隐藏NFC提示，开始文化之旅
5. **封面动画**: 观看《共产党宣言》封面复原过程
6. **音频播放**: 自动播放或手动触发陈望道翻译故事
7. **深度探索**: 点击经典段落按钮聆听专业朗读
8. **章节完成**: 完成体验后印章槽点亮，可前往下一展馆

### 备用体验流程（iOS/不支持NFC）
1. **进入页面**: 同样的庄严加载动画
2. **备用提示**: 显示"设备不支持NFC，点击墨水瓶按钮开始体验"
3. **手动触发**: 点击古典墨水瓶按钮
4. **后续流程**: 与NFC体验相同

### 关键代码文件
```javascript
// 主控制器类
class ManifestoHall {
  constructor() {
    this.nfcHandler = new NFCHandler();
    this.audioPlayer = null;
    this.elements = {};
    this.init();
  }
  
  // NFC标签验证
  validateManifestoTag(data) {
    const keywords = ['manifesto', '宣言馆', 'xuanyan'];
    return data.some(record => 
      keywords.some(keyword => record.data.includes(keyword))
    );
  }
}
```

## ❓ 常见问题

### NFC相关
**Q: iPhone无法使用NFC功能？**
A: iOS Safari不支持Web NFC API，会自动显示手动触发按钮。

**Q: Android设备NFC读取失败？**
A: 确保设备NFC已开启，使用Chrome浏览器，且网站使用HTTPS协议。

### 音频播放
**Q: 音频无法自动播放？**
A: 现代浏览器需要用户交互后才能播放音频，系统会智能引导用户操作。

**Q: 音频加载缓慢？**
A: 建议优化音频文件大小，使用CDN加速，或提供音质选择。

### 性能问题
**Q: 动画效果卡顿？**
A: 在低性能设备上会自动降低动画复杂度，可在设置中关闭动画。

**Q: 页面加载时间长？**
A: 实施资源预加载、图片压缩、CDN部署等优化措施。
